## 0.11.7 — 2026-09-04

### 2026-09-04 — 修复 `.env` 写入破坏发布目录硬链接

- 类型：Bug 修复（部署影响：修复后服务器上的控制群自动绑定、一键配置与群内“设置”写入才能真正持久化到 `shared\config\.env`）。
- 修改：`settings.py` 的 `.env` 写入由“临时文件 + `os.replace`”改为原地截断重写并 `fsync`。原实现会在首次写入时切断 `install_release.ps1` 建立的发布目录 `.env` → `shared\config\.env` 硬链接：受影响写入为首次入群自动绑定（`bind_admin_chat_id`）、`oopz-feishu setup` 的凭据写入和群内“设置”命令；下次升级重建硬链接后这些修改会丢失。
- 配置/数据迁移：无环境变量契约变化。当前生产服务器尚未部署，无存量脱钩数据；若某台服务器已运行过受影响版本并做过上述写入，升级前应人工比对当前版本目录 `.env` 与 `shared\config\.env`，把缺失行合并回 `shared` 版本。
- 部署步骤：按正常流程安装新发布包并重启网关，无需其他操作。`docs/DEPLOYMENT_STATE.md` 已注明 `.env` 写入必须保持原地写，`README_CLOUD_SERVER_DEPLOYMENT.md` 第 7 节已补充一键配置获取凭据的三种方式。
- 回滚：回滚代码即恢复旧写入方式；已正确写入 `shared` 的配置保留。旧版本在服务器上继续存在脱钩风险，不建议长期回滚使用。
- 验证：新增硬链接保持测试（不支持硬链接的文件系统自动跳过）；完整测试 `177 passed, 1 skipped`。

- 类型：新功能与配置入口（部署影响：服务器 Python 依赖集新增 `qrcode` 及其依赖 `colorama`，其余无需额外操作）。

- 验证：真实注册端点 `begin` 协议字段校验通过；`tests/test_feishu_setup.py` 12 项自动化覆盖；完整测试 `177 passed, 1 skipped`。

### 2026-08-27 — 分析异常退出的断点恢复

- 类型：运行可靠性与飞书会话可发现性修复。
- 运行变化：网关启动时检查未完成分析的锁文件；仅锁内 PID 已不存在且路径安全时才回收锁，并把分析生命周期写为“中断可恢复”。恢复入口会重新出现在“待分析”和“删除会话”，状态查询会提示恢复操作；存活 PID 的任务不被抢占。
- 数据与迁移：不改变 `.env`、报告格式或已有检查点。恢复分析复用已落盘的短/长窗口摘要，只请求缺失阶段；无需迁移或清理会话数据。
- 部署步骤：安装发布包后重启飞书网关。重启完成后检查“状态”，再通过“待分析”恢复中断会话；尚未完成的会话在恢复前不会出现在 PDF/完整报告列表。
- 回滚：回滚代码不会删除会话或检查点；但旧版本不会自动释放异常退出遗留的锁，必要时应先停止相关进程再按新版本恢复。

- 回滚：代码可回滚；共享模型不随代码回滚。更换模型修订版必须另行提供兼容与恢复说明。
