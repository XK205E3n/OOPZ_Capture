# 飞书部署交接

## 必需的本机配置

在 `.env` 中配置下列值，密钥不得发送到飞书群：

```text
OOPZ_FEISHU_APP_ID=
OOPZ_FEISHU_APP_SECRET=
# 可留空并在首次邀请机器人进群时自动绑定
OOPZ_FEISHU_ADMIN_CHAT_ID=
OOPZ_FEISHU_STATE_ROOT=feishu_state
```

网关采用飞书官方 `lark-oapi` 长连接。启用后，私聊被禁用，只有上述群 ID 的消息且 @ 机器人时才会被处理。群内没有管理员角色划分；成员共同控制录音、分析、发布和删除。

首次尚未取得群 ID 时，首选直接启动网关并将机器人邀请至目标群，程序会自动保存首次邀请的群 ID。`oopz-feishu discover-ids` 是机器人已在群内、无法重新触发邀请事件时的兼容手段；在目标群 @ 机器人发送“帮助”后，它只打印群 ID 和诊断用发送者 ID，不会执行业务操作。

## 事件订阅和权限

飞书应用必须已启用群消息和交互式卡片回调事件，并允许机器人加入受控群。公开发布还需要：

```text
OOPZ_FEISHU_PUBLIC_FOLDER_TOKEN=
OOPZ_FEISHU_BASE_APP_TOKEN=
OOPZ_FEISHU_BASE_TABLE_ID=
OOPZ_FEISHU_PUBLIC_INDEX_URL=
```

公开文件夹和 Base 必须向应用授予编辑权限。应用还必须开通 `space:document:delete` 和 `base:record:delete` 权限并发布包含这些权限的应用版本，才能永久删除公开文档及其 Base 索引记录；不建议仅为删除文档授予范围更大的 `drive:drive`。配置完整时，批准发布会创建文档、开启持链接阅读，并创建 Base 记录；撤回会关闭外部阅读并更新状态。删除或到期清理会分步记录远程资源的删除进度，远程删除失败时保留本地会话。

## 启动和验证

使用项目根目录的启动批处理启动网关。首启会发送启动消息和群内帮助；重启仅发送恢复消息。运行日志保存在 `logs/`，飞书事件、审计记录和发布决定保存在 `feishu_state/`。

建议按以下顺序验收：

1. 在受控群 @ 机器人发送“帮助”，确认私聊或未提及消息不触发操作；
2. 使用短录音完成“录音 → 转写 → 分析 → 群内报告”；
3. 检查批准发布后的文档与 Base 记录；
4. 测试撤回和删除，确认远程资源先于本地 Session 删除。

当前工作区已经存在真实的批准发布、公开文档、Base 记录和远程优先删除成功记录；上述步骤用于新服务器迁移后的复验，不是首次功能验收。
