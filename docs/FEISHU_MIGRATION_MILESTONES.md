# 飞书迁移里程碑（已完成的实现范围）

飞书是当前唯一远程集成面；QQ、NapCat 和 OneBot 相关生产代码与文档已移除。

1. **群控制边界**：官方长连接、受控群 allowlist、必须 @ 机器人、私聊禁用、固定规则命令解析与事件幂等。
2. **录音与分析交互**：域/频道选择、停止后的分析确认、待分析重试、报告/会话选择与删除确认卡片。
3. **群内交付与审查**：内部 Markdown、候选公开 PDF、批准/不发布/撤回卡片及本地发布决定审计。
4. **对外发布**：批准后创建飞书公开文档，写入 Base 索引；审查指纹防止内容被替换后发布。
5. **运营保障**：启动、关闭、重启通知；两类可见日志窗口；远程优先的保留删除；发布记录的协调和索引修复命令。

真实凭据端到端链路已完成验证；当前剩余的云服务器迁移和稳定性事项见 `PROJECT_PROGRESS.md`。当前使用与配置请以 README 和 `docs/OPERATIONS.md` 为准。
