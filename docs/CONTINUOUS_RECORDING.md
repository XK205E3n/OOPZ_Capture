# 录音与恢复规则

在飞书受控群 @ 机器人发送“开始录音 [时长]”后，系统先通过卡片选择 OOPZ 域和语音频道。时长可省略；省略时录音持续到群成员发送“停止”，或由安全条件结束。

无论是否指定时长，以下保护始终有效：

- 发起录音的群成员必须事先确认参与者均已知情同意；底层 Worker 请求仍固定记录 `consent_confirmed=true` 作为审计前置条件；
- 频道无人超过 `OOPZ_EMPTY_CHANNEL_TIMEOUT_SECONDS` 时安全结束；
- 达到 `OOPZ_CUTOFF_LOCAL_HOUR` 的北京时间强制结束；
- OOPZ 连接断开时在设定窗口内重连，超时后结束并保留可恢复状态；
- 分片转写、修复和分析均写入 Session 文件，不依赖飞书长连接持续在线。

停止录音后，系统完成转写并发送分析选择卡片。选择“暂不分析”不会删除录音；之后发送“待分析”可以选择同一 Session 继续。分析失败也保留窗口检查点，重试时不会重复调用已完成的窗口。

本地状态窗口只显示进度；它不改变录音器的文件状态。请使用项目根目录的启动、关闭和重启批处理管理网关，避免直接结束进程而错过生命周期通知。
