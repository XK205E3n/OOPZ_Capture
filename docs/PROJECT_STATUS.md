## 一句话

目标流程"飞书控制 → 录音转写 → 自动分析 → 精华图 → 发到飞书群（可选再发 QQ 群）"已在 `main` 完成并**通过验收，转入长期运行**：2026-10-04 首次部署，2026-10-07 起为 0.13.2（systemd，开机自启）。多场 6～9 小时真实录音已验证录音、转写、音频删除、出入记录、头像、分析出图、飞书发送与 QQ 发图。
